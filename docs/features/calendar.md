# Calendar

When a refresh fails, Calendar keeps the last dates, selected day, and Updated time and shows a retry notice; Retry refreshes the dates, while an expired session clears the screen.

Calendar also shows both partners' Outlook meetings, with Central start times, and planned tours on open deals, read once for the shown month or week. Outlook only syncs about the next two weeks, so a quiet line says so, and a later day with no meetings does not mean the partner is free. A partner whose calendar is stale or could not be read gets a plain note, and the dates and next steps still show. The read sits behind the same Deals switch as the rest of Calendar; when the engine does not serve it, the page says nothing about meetings.
